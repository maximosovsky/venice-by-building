# Fonts

The latin subsets of two fonts, the same files thethirdscript.com serves:

- `cormorant-garamond-latin.woff2`, `cormorant-garamond-italic-latin.woff2`: Cormorant Garamond, Copyright 2015 The
  Cormorant Project Authors (github.com/CatharsisFonts/Cormorant).
- `inter-latin.woff2`: Inter, Copyright 2016 The Inter Project Authors (github.com/rsms/inter).
- `im-fell-english-sc-latin.woff2`: IM Fell English SC, by Igino Marini (fonts.google.com/specimen/IM+Fell+English+SC).
  Latin subset only: the face has no Cyrillic, so Russian headings fall back to Cormorant Garamond.

All are licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org), which each file also
names in its own metadata.
